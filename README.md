# تذكيراتي 🔔🚗

تطبيق تذكيرات يطلع بالتلفون وبقائمة تطبيقات **Android Auto**.

- ضيف تذكير (مرة وحدة / يومي / أسبوعي) من التلفون.
- وقت التذكير يطلع إشعار بالتلفون، وبالسيارة يطلع على الشاشة كرسالة وينقرا بالصوت.
- من شاشة السيارة: قائمة التذكيرات، «تم ✓»، «أجّل 10 د»، و«تذكير سريع» (بعد 10 د / نص ساعة / ساعة / ساعتين).

## حتى يطلع بأندرويد أوتو
1. إعدادات Android Auto ← دوس على «الإصدار» 10 مرات.
2. النقاط الثلاث ← إعدادات المطوّر ← فعّل **Unknown sources / مصادر غير معروفة**.
3. «تخصيص مشغّل التطبيقات» ← أشّر على «تذكيراتي».

## البناء
GitHub Actions يبني الـ APK تلقائيًا (لازم Secrets: `SIGNING_KEY` و `SIGNING_PASSWORD` — نفس قيم مشروع mosul-salah).
